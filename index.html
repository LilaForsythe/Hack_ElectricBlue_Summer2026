The Instrument

Built from the weather, wired for the stage

Every panel started as a CAD sketch of a storm: a rounded cloud body, a raindrop base, and a lightning-shaped power switch. Underneath, a Raspberry Pi Pico drives eight I2S-synthesized tones across a full octave and reads live volume off an onboard potentiometer.

⛈
Add instrument photo — Stormcaster.jpg
  • Range C4 – C5, one full octave, 8 notes
  • Volume control Digital, potentiometer → I2S gain, live
  • Enclosure Cloud body / raindrop base / lightning switch
  • Brain Raspberry Pi Pico (MicroPython)
  • Audio out I2S DAC, 22.05kHz mono
  • Data out USB serial → this website, live
